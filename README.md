# AutoGen HR Assistant Agent

A simple AI agent built using AutoGen and OpenAI's `gpt-4o-mini` that generates a concise 5-line job description for any specified role.

## Features
- Built with Microsoft AutoGen (`autogen-agentchat` & `autogen-ext`).
- Interactive runtime role input.
- Real-time streaming response using AutoGen's `Console`.
- Clean shutdown closing the model client.
